# Đảo Đèn Lồng Phase 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Đêm 1 chơi được và headless đúng Test Contract v1.0, có bằng chứng, gắn tag `phase-1`.

**Architecture:** Hướng B: một scene Godot (`Main.tscn`) chứa node và physics. `Game.gd` giữ luật chơi. `HeadlessDriver.gd` bật khi có user-arg `--headless-run`, đưa input theo tick và ghi JSONL. Test là script Python stdlib, gọi headless rồi kiểm tra JSONL.

**Tech Stack:** Godot 4.7.2 (GDScript). Docker (Linux, Godot 4.7.2 headless). Python 3 stdlib cho test runner.

**Spec:** `docs/superpowers/specs/2026-11-20-dao-den-long-design.md`. Test Contract nằm trên lab board, tab Phase 1.

## Global Constraints
- Godot local: `D:\VinAI\Godot_v4.7.2-stable_win64.exe\Godot_v4.7.2-stable_win64_console.exe`. Biến `GODOT` trỏ vào file này.
- Headless: `godot --headless --path . --fixed-fps 60 -- --headless-run --seed N --night 1 [--scenario f] [--inputs f] --ticks N --out f.jsonl [--snapshot-every 10]`.
- Exit code: 0 khi xong; 2 khi inputs/scenario sai định dạng; 1 cho lỗi khác, thông điệp in ra stderr.
- 60 tick mỗi giây. Snapshot tick 0 là trạng thái trước input. Bước k đọc input của tick k; event ghi `tick = k+1`. `time_left_s = dur - steps/60`.
- Khoảng cách đo trên mặt XZ và tính là trong bán kính khi `<= r`. Tọa độ làm tròn 3 chữ số. Cùng seed, scenario và inputs thì output giống hệt từng byte.
- Gameplay chỉ chạy trong `_physics_process`. Mọi RNG là `RandomNumberGenerator` lấy seed từ `--seed`. Không dùng `randf()` toàn cục.
- Tuning lấy đúng bảng trong spec (flames 100, damage 34, ...). Đọc từ `game.contract.json` để chỉ có một nguồn sự thật.
- Phần sáng tạo của Phase 2 không chạy khi có `--headless-run`.
- Commit nhỏ bằng skill vietnamese-dev:vn-commit, không ghi co-author AI. Tag và push phải hỏi user.

## Review Focus
1. Frame inputs có `tick` trùng hoặc giảm, `move` không phải mảng 2 số, JSON hỏng: phải thoát với mã 2. Test nằm ở Task 3.
2. Game kết thúc trước khi chạy đủ `--ticks`: dừng ngay, dòng `end` có `ticks` bằng số bước thực tế. Test nằm ở Task 4.
3. `move` dài hơn 1, ví dụ [1,1]: chuẩn hóa về độ dài 1, không chạy nhanh hơn `player_speed`. Test nằm ở Task 3.
4. Scenario đặt đèn `lit: true`: không cộng điểm, không phát event, và vẫn tính vào điều kiện thắng. Test nằm ở Task 4.
5. Pulse trong lúc cooldown hoặc khi mang dưới 2 đom đóm: không có event, không trừ gì. Test nằm ở Task 4.

- [ ] Viết các scenario test, mỗi test một hàm. Mọi test đặt `random_motes/shades: false`.

  - `deposit_lit`: carried 6, đứng cách L1 2.5 m, interact → `deposit {L1,6,6}` rồi `lantern_lit`, score +100. `partial`: carried 8 → nạp 6, còn mang 2.

  - `safe`: L1 đã thắp, shade đuổi không vào được trong 7 m quanh L1. `prelit`: `lit:true` từ scenario → score 0, không có event.
  - `win`: 4 đèn đã thắp sẵn, nạp nốt L5 → `game_over won all_lit`, cộng thưởng thời gian và thưởng flames, dừng sớm, `end.state won`. `dawn`: `time_left_s 1` → lost dawn ở tick 60. `no_flames`: 3 lần bị chạm → lost no_flames.
